# Originality boundary

## Reference allowed

`Nyankomintsu/world-execute-me-lyric-mv` is used to understand **production discipline and quality control**:

- director brief before implementation;
- explicit priority/rules documents;
- section-by-section production;
- deterministic rendering;
- first/key/last-frame inspection;
- contact-sheet review;
- full-preview QC;
- regression checks after shared-engine changes;
- decode/sync/flash/luma validation;
- temporary CI for heavy rendering.

Its public prompt documents are treated as examples of how specific a serious directing brief must be.

## Reference not reused

Do not copy, adapt line-by-line, port, or reuse:

- source code;
- renderer implementation;
- scene modules/components;
- character silhouettes or their poses;
- Claude character design;
- visual compositions;
- storyboard shot sequence;
- chat script;
- error script;
- scene timing data or cue maps;
- lyric timing data;
- generated images or rendered video;
- custom graphics/assets;
- exact three-mode visual structure;
- exact palette semantics;
- exact narrative of user changing Claude's body/settings, abandonment, loop, or unread final message.

## Our independent choices

The GPT reboot uses an original concept:

- GPT is a visible editorial-studio character with a readable face, not a three-ink faceless Claude silhouette;
- the user and GPT are co-authors at a shared desk rather than operator and configurable AI;
- visual modes are DESK / WORLD / TRACE;
- tactile paper, proof sheets, collage, pencil, and editorial illustration replace dark interface/print/code modes;
- cobalt marks GPT, sunflower marks the user, vermilion marks correction;
- narrative arc is curiosity → play → misread → revision → collaboration → open continuation;
- errors are editorial mismatches and physical failed constructions, not red system corruption;
- ending is shared unfinished work, not an abandoned unread message.

## Audio and lyrics

If the project ultimately uses `world.execute(me);` or another copyrighted song, audio and lyrics are supplied by the user outside Git and are not redistributed.

Timing must be measured independently from the user's source audio. We may learn *how* the reference project measured cues, but we do not import its cue values or lyric timing files.

## Failed prototypes

`temp-work/gpt-signal-mv` is not a code base for the reboot. Its failures are lessons only:
- generic cyberpunk palette;
- abstract “AI process” imagery;
- insufficient character acting;
- low shot density;
- weak art direction.

No source file from that workspace should be copied into this reboot.
