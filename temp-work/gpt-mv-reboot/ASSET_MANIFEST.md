# Approved style-frame assets

Stage 2 uses six original GPT style frames generated for this project. They establish the current visual direction: luminous anime-inspired illustration, blue/cream daylight-to-golden-hour palette, a silver-haired GPT character, a dark-haired user seen mostly from behind, desk/chat/world motifs, paper fragments, and an emotionally warm rather than cyber-occult tone.

These are **project-original outputs**. They are not assets from the Claude reference repository.

## Important limitation

These six frames are full illustrations, not an animation-ready character pack. They are enough for the hero gate using camera movement, typography and foreground compositing, but not enough for a full 2–3 minute film without repetition.

Before full production, generate an **isolated original GPT character pack** in the same design language: neutral bust, profile, listening pose, thinking pose, reaching pose, happy close-up, worried close-up, full-body standing, back view, hands, and several user-facing interaction poses. Prefer clean backgrounds or alpha so the compositor can place them in new layouts.

Do not attempt to redraw these poses procedurally.
