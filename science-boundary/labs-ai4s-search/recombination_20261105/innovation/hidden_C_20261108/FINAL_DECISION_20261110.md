### Redefined scientific objective — not repaired energy and not designated hidden C

The primary learning/selection reward should be **a first-time, high-quality, *new-to-the-search* symmetry orbit** per unit real compute:

```
initial visited V0 := {canon(A), canon(B)} plus any pre-existing search history
on accepted repaired or evaluated state s_t:
  c := canon(s_t)  // exact 8-fold LABS symmetry class
  r_t(eps) = 1{E(s_t) <= floor((1+eps)*E_reference) and c not in V_{t-1}}
  V_t := V_{t-1} union {c}
under fixed wall-time T:
  G_eps(pi,T) = number of distinct qualifying new orbits first encountered
```

**Two different notions of novelty must be reported**, never conflated: (a) *search-history new* `c not in V_t`, which can be an already published optimum C; and (b) *source-registry new* `c not in global frozen published/reference corpus`, which forbids calling recovery of known C a newly discovered frontier structure. Both exclude returning to input A/B. Define `eps=0.05` a priori as primary near-frontier, `eps=0.10` as lower-quality secondary; also report strict best-known **record improvement** separately. At every length use the known optimum E* only as an offline quality ruler, never to encode the hidden target's bits. Full budget includes candidate generation, exact E, model inference, local repair, and model-training amortization where relevant. Report unique orbit identities and source-orbit cluster units, not only success counts across correlated seeds. C-specific recovery is auxiliary; C-shell (X generated by perturbing C) is **privileged denoising only**, not A/B blind composition.

The old loss `MSE(predict E(Repair(s,a)))` is not a consistent surrogate for these objectives: return A and reach a distinct optimum C have the same E. It can reward repeated visits to old optima. A new generator is not warranted merely because this Ridge target was misaligned.

## Literature and strongest available control: corrected isolated four-spin

The paper's main TTS metric is full sequence energy evaluations from a different initial condition, whereas ours is **150ms end-to-end on fixed high-quality damaged X**, with the same common first native 64-Tabu repair(X), a distinct task. Our code is *paper-inspired*, not source/bit-for-bit faithful authors' code.

**Found and independently verified mathematical bug in earlier in-repository independent N100 probe** `science-boundary/labs-100/code/isosubsys.cpp`: it incorrectly retains a two-spin cross term whenever endpoints have even index difference. For isolated four-spin LABS, even difference is insufficient: the **midpoint must itself belong to the selected subsystem**. Independent Python exhaustive 137,088 position/assignment cases for n4..17 passed for corrected midpoint formula. The [corrected exact native C++ n4 implementation](four_spin_isolated.cpp) also passed exhaustive small-size isolated-objective selftest, independent global E and canonical score testing. Cross-topic issue **[#23](https://github.com/teddyli18000/web-ingest/issues/23)** notifies the labs100 owner; we did not change their code.
