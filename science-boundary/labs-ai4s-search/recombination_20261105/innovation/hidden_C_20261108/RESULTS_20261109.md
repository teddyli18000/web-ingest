# Hidden-C repair study — exact evidence, 2026-11-09

## Strict first experiment and frozen protocol

All training optima: N46 E131 (3 distinct eightfold orbits); validation N47 E135 (6); first held-out test N50 E153 (3). [Packebusch–Mertens 2016](https://doi.org/10.1088/1751-8113/49/16/165001) enumerated all optima for N≤66. A, B, C are distinct symmetry orbits. C-shell X is generated using hidden C and constitutes an oracle-conditioned **diagnostic**, never A/B-blind discovery. Search executables only read A/B/X and model coefficients; C vault is opened in a separate exact-energy scorer after search. This is procedural, not cryptographic, blindness.

Original [frozen N46/N47 model](results/frozen_models/training_audit.json) SHA `b47759a27123c3ef066c3e345f9eafbf32eb650a9f92aef4a55010230096cba9`. First [N50 sealed test](results/test50/verdict.json): 144 matched X, six methods ×150ms, **670,888 exactly verified native repair events**. All AB_blind methods hit hidden C **0/72**. Every C_shell method hit C on **the same 17/72 direct-repair(X) events**, none after that initial common repair. A defect was discovered afterward: the raw-E bank included an unchanged j=0 candidate and often chose no action. **Preserve negative data, but do not call this a strong search comparison.**

## Posthoc repair of no-op classical baseline (N50 now EXPOSED)

Decision to force nonzero actions was made **after seeing N50 results**. New N50 RNG seeds are not a new strict sealed target test; all results below are **exploratory**.

Separate [forced model](results/forced_models_v1/training_audit.json) SHA `2abb727677b9c065b624322f1446fc950987d2c64fc41396e4b90e80c5ad576b` fits N46, selects N47 using j1..5. In 576 N47 candidate banks, actual repaired E selected by immediate-E / cheap energy+history / full joint correlation+history / impossible all-five-after-repair oracle was respectively **221.792 / 219.118 / 219.333 / 203.160**. No incremental benefit from joint features over cheap history on the N47 length.

[New-seed N50 six-arm costed replay](results/test50_forced_v1/verdict.json), [lossless complete data hashes](results/test50_forced_v1/lossless_archive_provenance.json): 144 contexts×6×150ms, **697,569 exact-verified events**. In A/B-blind: all six methods hit hidden C **0/72**. True-B raw-E repair found **2/72 non-A exact optima**, single-source ILS found **1/72**; [orbit forensics](results/test50_forced_v1/sessions.tsv) show **all three are the already supplied B parent orbit**, not C. Other methods (A-only, fake B, cheap and joint learned) found zero alternative exact-optimum orbits. C-shell: initial shared direct repair recovers C **21/72**; only ILS adds **one** post-initial C recovery, learned and real/fake B none. No extra neural architecture earned.

## Posthoc action-bank oracle and altered state representation

[Certified five-action bank reachability](verify_probe.py), [N46](results/bank_train46/bank_reachability.json), [N47](results/bank_validation47/bank_reachability.json), [N50](results/bank_test50_forced_v1/bank_reachability.json): 3 lengths ×144 states ×3 real/fake/A donor supports ×5 actual moves = **6480 complete independently scored repairs**. All A/B-blind states at each length: **zero C, even for an impossible oracle selecting among these fully repaired proposals**. For failed C-shell direct repair, greedy incumbent five-action banks had target C reachable at N46 **1/57**, N47 **0/54**, N50 **0/51**. Better ranking of these masks cannot help where no correct action exists in the candidate pool.

[Original-X retention experiment](compare_branches.py) and exact verified [N46](results/branch_train46/branch_causal_diagnostic.json), [N47](results/branch_validation47/branch_causal_diagnostic.json), [N50](results/branch_test50_forced_v1/branch_causal_diagnostic.json): **12,960** further complete reparations, paired same source X/donor, compare keeping original X as an alternative to greedy repaired incumbent. In C-shell first-repair failures, *true B* five-action bank can recover hidden C from retained X at N46 **3/57**, N47 **3/54**, N50 **1/51** versus greedy 1/57,0/54,0/51. N50 target-positive witness `n50_tri0_rep14_k4_C_shell` begins **4** bits from hidden C; greedy repair moves its incumbent to **20** bits away; neither frozen model selects the accessible C-return proposal. N50 overall mean X→C symmetry Hamming in 51 failed C-shell cases **9.49**, greedy incumbent→C **18.33**. Fake B reaches N46/N47 targets as often or more, and **no AB-blind scenario at any length reaches C even with X preserved**. This is *structural state-loss evidence*, not new blind C discovery.

## Next gate

A new [full-cost two-state retention source](run_retention.py) compares alternating proposals from original X and incumbent versus incumbent-only, using the **same exact 150ms full repair budget** and all six methods. Results will be cited only after independently recomputing *every* pre/post LABS E, every eightfold orbit, and verifying the identical shared first repair; C is read only after both searches.

**Decision:** Currently there is no evidence for adding deep neural architecture. Potential has moved from ranking fixed donor masks to (1) ensuring candidate C is actually reachable, (2) keeping independent structural states alive while an incumbent moves into an unrelated lower-energy basin, and (3) detecting genuinely third-orbit structures, distinct from cloning known A or B. Only 3 independent target optimum orbits at N50, and all N50 follow-up experiments are posthoc, not strict external validation.
