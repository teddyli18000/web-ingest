# AI4S search-method discovery for low-autocorrelation binary sequences

## Question

Can learning or program discovery produce a **reproducible, transferable improvement in low-autocorrelation binary sequence (LABS) search**, especially at escaping difficult local minima or selecting promising search basins? A verified improvement at length 100 is an ambitious secondary outcome, not a claimed result.

This is an independent **methodological research direction**, distinct from the existing `science-boundary/labs-100/` record-construction effort. Preserve distinct evidence and do not modify the other topic's files.

## Research aim

Investigate whether a genuinely different search representation, learned decision mechanism, or discovered optimization program can outperform strong non-learned methods on **unseen LABS instances**, under fair matched-compute evaluation. Assess current literature and the actual source code before treating a method as novel.

The original working hypothesis is that evaluating **post-relaxation basin outcomes** for coordinated moves may contain more useful information than rewarding an immediate bit flip. Treat this as a hypothesis to test or replace, not a prescribed solution.

## Next steps

**Do not keep tuning the same fixed twelve-spin macro/lag weights, nor train an unvalidated dual-branch model.** First acquire **persistent long-stagnation native solver checkpoints** and multiple independent *truly near-record* non-near-skew lineages (especially N99/100); distinguish native GA recombination jumps from single contiguous Tabu trajectories. Derive a new *joint signed-correlation-cut generator* from the exact identity `Ck(s^M) = Ck(s) - 2·Σ_{i: M_i ≠ M_{i+k}} s_i s_{i+k}`: preserve low-stress spectral modes while allowing coordinated multi-bit structure shifts and odd/even Pareto tradeoffs. Test whether such candidates can yield near-source, symmetry-distinct local optima where the current classical fixed-12 swap optimizer cannot. Any learned generator must beat (a) costed mask-space local optimization, (b) published old/native MTS crossover and repaired controls, **then** genuinely modern 2025 GPU-MTS/2026 SAW under identical *entire-solver* compute and unseen lengths. Preserve [previous target-deformation failures](frontier_deformation/README.md) and [full-history audit negatives](audit_20261029/README.md) rather than retrying the same weight search. The **N99 E577 skew → E553 non-skew** published pair is a known-answer structural calibration only, never a secret improvement that our algorithm rediscovered.
