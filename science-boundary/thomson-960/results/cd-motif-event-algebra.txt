Thomson N=960 — C->D elementary motif-event algebra
Date: 2026-10-29

Context
-------
Direct Delaunay analysis represents C/D/B/A as twelve charge-+1 five-vertex
defect components, each with a binary internal 7-7 adjacency ('twin bit').  C is
C3 symmetric and D differs from C in an especially local way: 11/12 components
retain their point-label set while one component changes from conventional to
twinned.  Only four labels change coordination class:
  602 5->6, 822 6->7, 831 6->5, 919 7->6,
creating twin edge (822,842).

This makes the full nonlinear C->D pointwise displacement field a concrete
candidate for an elementary defect rewrite event.  Since C is C3 symmetric,
rotating that displacement field by 120 and 240 degrees gives two exactly
equivalent events e0,e1,e2.

Local construction
------------------
Using the exact saved C and D coordinates, define each event by the spherical
pointwise log map C->D and its C3 group copies.  Compose events sequentially by
parallel-transporting each C-based tangent field from C to the current point
configuration before applying the sphere exponential map.  After each composed
start, fully release all 960 points with the stable long-double pair-difference
L-BFGS objective.

The RMS angular size of each elementary event field is ~0.003239710674 rad.

Interpretation
--------------
The C3-equivalent local rewrite does not behave like three independent binary
flips.  Its nonlinear/global elastic completion has a closed event algebra:

  C --e0--> D0
  C --e0 e1--> C3(B)
  C --e0 e1 e2--> C

(up to which equivalent event / C3 image is chosen).

This provides direct constructive evidence that the low-energy R/A/B/D/C graph
can be generated by discrete defect-rewrite events coupled to a global elastic
field.  The event composition is path/group dependent; a naive energy model
based only on the number of twinned motifs is insufficient.

Search consequence
------------------
Future defect-level search should treat an event as a full learned nonlinear
point-displacement field (local topological rewrite plus global shear/elastic
response), then compose symmetry- or motif-related event fields before final
relaxation.  Do not model the twelve motifs as independent Ising variables.

The analogous event family connecting B/A (and, eventually, A/R once the live
record coordinates are directly available) is the next high-value discrete
operator.  The C->D event family itself is now saturated at unit-scale through
all three C3-equivalent copies: it closes on C/D/B and gives no new minimum or
record candidate.
