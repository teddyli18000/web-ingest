4. Reformulation
----------------
The next search should not merely increase the old beam width/depth. Add a cascade-aware state variable:
- retain the evolving active edge signature;
- after fixed adaptation, perform a modest common-restraint probe of the active support;
- measure remote root-glide states and threshold ratios relative to the root minimum;
- reward paths that trigger remote glides or strongly reduce their crossing thresholds;
- use Pareto beam retention so intermediate fixed energy and remote-cascade potential are separate objectives, rather than collapsing both into one scalar fixed-energy score.

Positive-control requirement: the cascade-aware search must still recover q1->q2->q3->A from orbit4.

If the new representation still only reaches R/A/B for several independent first orbits, the next reformulation should move from individual dependent flips to scar-component / grain-boundary state variables rather than only increasing depth.
