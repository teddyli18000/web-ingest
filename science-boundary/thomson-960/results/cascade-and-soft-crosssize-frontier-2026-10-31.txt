Remote follower softening is predictive
----------------------------------------

field until remote live-root glides become soft and flip spontaneously.
Dedicated run 41101441646 measured this before the flips:

  orbit3 (21,230)->(74,363): threshold 0.00318536 at the two-flip source,
    0.00159478 after q3-fixed, then spontaneously flipped already at kappa=100.

  orbit2 (79,134)->(35,323): threshold 0.00440156 at source,
    0.00364388 after q3-fixed, 0.00234819 at kappa=100,
    0.00169167 at 70, 0.00114886 at 50, 0.000524109 at 30,
    0.000182617 at 20, then spontaneously flipped by kappa=10.

Therefore remote-follower threshold softening is a measurable precursor of a
nonlocal cascade, not a post-hoc description.

Cross-size campaigns: what they actually ruled out
--------------------------------------------------
Amore-Wales neighboring-N propagation motivates cross-size transfer, but prior
local campaigns here used hard particle insertion/deletion followed by full
relaxation.  Their failures should not be generalized to all cross-size
representations.

N932 -> N960, run 40991011714:
  historical N932 source had 8 twin motifs.
  one-particle-at-a-time insertion with tiny beam progressively erased them.
  best motif-policy endpoint = 444369.0425244513, live +0.650118254,
  final twin count 0.

N920 -> N960, run 40991204788:
  source itself had twin count 0.
  best motif-policy endpoint = 444370.1206861578, live +1.728279960.
  This is structurally a poor teacher for the live 12-scar regime.

N972 -> N960 hard 12-point T-orbit deletion, run 40991054819:
  N972 source had 24 dislocations / 12 twin edges.
  all 81 generic size-12 T orbits were deleted in one event and fully relaxed.
  best direct child orbit25 = 444369.7544781622, live +1.362071965,
  with only 2 twin motifs remaining.  Several other hard deletions retained
  more twins but remained high energy.

Common failure mode: the discrete particle-count jump plus immediate free
relaxation destroys global scar organization before it can be transferred.

Soft cross-size reformulation
-----------------------------
Run 41184513082 tests a different representation.  For one selected N972
12-point T orbit, the 12 would-be-deleted particles are held fixed at their
parent positions as external Coulomb sources with charge lambda.  The other
960 particles are optimized while lambda is continued smoothly from 1 to 0.
At lambda=0 the ghosts decouple exactly and the active particles are a genuine
N960 Thomson configuration, followed by ordinary stable repolish.

Only two informative orbit families are tested initially:
  orbit25: lowest-energy old hard deletion, far from defect cores;
  orbit5: old hard deletion retained all 12 twins.
Each uses linear-like and geometric lambda schedules.  This is a mechanism test,
not an exhaustive 81-orbit scan.

Decision rules
--------------
1. Any float endpoint below R by >2e-7: stop exploratory branching and enter
   independent stable repolish + upstream record recheck + official verifier.
2. If cascade-aware v2 produces a novel low basin or a high-cascade R-returning
   state, expand only that branch; do not blindly deepen all first orbits.
3. If v2 only returns R/A/B despite a valid orbit4 positive control, the next
   topology representation should change a held-fixed assumption (for example
   multi-scale restraint probes or A-centered dependent chains), not merely
   increase beam width/depth.
4. If soft N972 transfer preserves scar/twin organization much longer and beats
   old hard deletion materially, exploit soft occupancy continuation.  If it
   collapses to the same high families, retire fixed-ghost fading and consider
   a richer collective occupancy/strain-field transfer rather than more lambda
   schedules.
