CURRENT SEARCH B — +/-3 ENTIRE C3 ORBIT SIZE EXCHANGE
New constructive algorithm code/search_c3_orbit_size_exchange.py.
This is qualitatively distinct from earlier N960<->N959/N961
single-particle bounces (which often created high 23-dislocation
descendants) and from N972->N960 full 12-particle T orbit removal.
A C3 orbit contains 3 equal charges:
  N960 (320 C3 orbits)
   -> remove any orbit, physically optimize N957 (319 C3 orbits);
   -> add an unrelated triplet at a low full-orbit insertion energy,
      physically optimize N960 (320 C3 orbits); or reverse
  N960 -> add triplet N963 (321 C3 orbits)
   -> remove a distinct orbit, optimize N960.
This preserves C3 throughout size excursion, allowing a collective
scar change without the asymmetric +1/-1 vacancy endpoint.
Then symmetry breaking and unconstrained true N960 Coulomb relaxation.
The code independently computes stable exact Coulomb forces and
freezes ANY subrecord N960 xyz coordinates.

The orbit insertion exact Coulomb increment for point y and its 120°
rotations, given a C3 source X, is:
  Delta_add = 3 * sum_{x in X} 1/||x-y|| + 3/d(y),
  d(y) = sqrt[3(1-y_z²)].
For deleting orbit {a,Ra,R²a}, source potential against other 3m-3
charges is p(a), the exact energy removed is:
  Delta_del = 3*p(a) + 3/d(a).
First version incorrectly subtracted 3/d and treated self excluded
entries as dot=-1 instead of inverse distance zero. Fixed source in
commit 00b17dd (self-test independently computes full N960 and N957
energy and confirms three representative removal differences within 3e-7).
Original two-seed pilot Action 42456406401 uses biased ranking but
generates genuine valid N960 endpoints; corrected two-seed Action
42456551742 (80 cycles each) runs the accurate ranking with compulsory
energy identity check. Old T and R sources both used.

BACKGROUND and why this matters
The Amore/Wales 2026 JCP 165 164104 cross-size study reported
propagating favorable spherical configurations between adjacent N;
upstream Few Shots winner also reports failure for simple Riesz
homotopy and isolated defect moves. Earlier project N±1 live-centered
bounce tested a few rank choices, no E<R. Triplet-group orbit moves
are not equivalent to those single-particle changes: intermediate
N957/N963 preserves a C3 symmetry, all 3 particles are related,
and the return alters a different orbit.
