# Exact closure of all outside×outside points with both supports of size at most two

Status: **closed unconditionally at nonpositive raw core gain.** This result does not assume `alpha(C7^5) <= 367` and does not depend on terminal-periphery penalties.

Pinned geometry: Tandon/BPZ commit `c753408492dde92a239708986d16c15dbf6c3235`, with 359-point core factor `B`.

## Factor universe

For every five-dimensional point `z notin B`, define its core support

`S(z) = N[z] intersect B`.

Restrict to nonempty supports of size at most two. The exact pinned census is:

- 50 factors with support size 1;
- 375 factors with support size 2;
- 425 factors total.

These 425 factors give `425^2 = 180,625` possible ten-dimensional outside×outside points `(u,v)`. Their core footprint is the rectangle

`S(u) x S(v)`

of size 1, 2, or 4. Because both supports are nonempty, these points are outside the fixed terminal safe blocks; in any case the argument below only charges mandatory core deletions, so extra terminal losses can only make the score worse.

## Owner-clique assignment

`code/bpz_low_support_owner_clique_assignment.py` constructs a map

`f(z) in S(z)`

such that for every core owner `b in B`, the fiber

`F_b = {z : f(z)=b}`

is a clique in the `C7^5` confusability graph.

The certificate is extremely small:

- the 50 singleton-support factors are forced;
- each of the 375 two-owner factors has one Boolean choice;
- whenever two nonconfusable factors could both be assigned to the same owner, a 2-SAT clause forbids that simultaneous choice;
- exact instance: **375 Boolean variables, 420 clauses** = 35 unit + 385 binary;
- the built-in SCC solver returns SAT;
- resulting nonempty owner fibers: 193;
- largest owner fiber: 7 factors;
- independent replay of every pair inside every owner fiber finds **0 nonconfusable pairs**.

The full assignment is regenerated by the checker rather than hand-transcribed.

## Product injection

For every candidate ten-dimensional point `(u,v)`, assign the core cell

`phi(u,v) = (f(u), f(v))`.

This cell lies in its mandatory core footprint because `f(u) in S(u)` and `f(v) in S(v)`.

Now suppose two candidate points `(u,v)` and `(u',v')` receive the same core cell. Then

`f(u)=f(u')` and `f(v)=f(v')`.

By the owner-clique property, `u` is confusable with `u'` in `C7^5` and `v` is confusable with `v'`. Therefore `(u,v)` and `(u',v')` are confusable in `C7^10`.

Consequently, on any independent set `I` of these 180,625 outside×outside candidates, `phi` is injective. Every image cell is a core cell that must be deleted before its candidate can be inserted. Hence

`|I| <= |phi(I)| <= number of deleted core cells`.

So the raw core score change is never positive. Any deleted terminal-periphery points only decrease it further.

## Consequence

No construction using only outside×outside additions whose two five-dimensional supports are both nonempty and at most two can improve the 134,753 record, even when:

- arbitrarily many different support rectangles are mixed;
- rectangles share core cells;
- the selected points are not confined to any previously enumerated rectangle/product family;
- exchange radius is unbounded.

This is stronger than checking the 138,384 support-pattern rectangles individually. Indeed the exact local rectangle census gives alpha 1 for every such rectangle (2,500 cost-1 ties, 32,200 cost-2 rectangles, 103,684 cost-4 rectangles), but the owner-clique assignment additionally rules out any positive gain obtained by combining different rectangles and sharing core cells.

The next qualitatively new outside×outside layer is support size **3**. The same proof strategy becomes a list-assignment SAT problem with domains of size at most three; if it is feasible, it would close all candidates with both supports at most three by the same product injection argument.
