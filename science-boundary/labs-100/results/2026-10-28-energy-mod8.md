# 2026-10-28 exact energy/product congruence for N=100

## Statement

For any length-100 sign sequence `s_i in {+1,-1}`, let

```text
P = product_i s_i.
```

Then the LABS energy satisfies the exact congruence

```text
P = +1  =>  E_even = 4 (mod 8),  E = 6 (mod 8),
P = -1  =>  E_even = 0 (mod 8),  E = 2 (mod 8).
```

Here `E_even = sum_{k even} C_k^2`. Since every odd-lag correlation has odd parity at N=100, the odd-lag contribution is always

```text
E_odd = 50 (mod 8).
```

Thus `E mod 8` is determined by the product of all 100 signs.

## Proof

For an even lag `k`, write `L=100-k` and let `m_k` be the number of negative terms among the `L` products `s_i s_{i+k}`. Then

```text
C_k = L - 2 m_k.
```

The parity of `m_k` is determined by the product of the lag terms:

```text
(-1)^m_k = product_{i=1}^{100-k} (s_i s_{i+k}).
```

For `k<50`, the lag products at `k` and `100-k` have the same total product: after cancellation both reduce to the product of the first `k` signs and the last `k` signs. Hence

```text
m_k = m_{100-k} (mod 2).
```

Now pair every even lag `k=2,4,...,48` with `100-k`. Since

```text
C_k/2       = (100-k)/2 - m_k,
C_{100-k}/2 = k/2       - m_{100-k},
```

the two half-correlations have the same parity because their parity sum is

```text
50 - m_k - m_{100-k} = 0 (mod 2).
```

Therefore either both `C_k,C_{100-k}` are divisible by 4 or both are `2 mod 4`, and in either case

```text
C_k^2 + C_{100-k}^2 = 0 (mod 8).
```

The only unpaired even lag is `k=50`. Here

```text
C_50 = 50 - 2 m_50,
(-1)^m_50 = product_i s_i = P.
```

So `C_50/2 = 25-m_50` is odd exactly when `m_50` is even, i.e. exactly when `P=+1`. Hence

```text
C_50^2 = 4 (mod 8) if P=+1,
C_50^2 = 0 (mod 8) if P=-1.
```

All other even-lag pairs contribute `0 mod 8`, proving the `E_even` statement. Every one of the 50 odd correlations is odd, so each odd square is `1 mod 8`, giving `E_odd=50=2 mod 8` and the total-energy statement.

## Independent checks

A direct exact scorer was used on random length-100 sequences and the congruence held in every checked case. The public incumbent has

```text
E = 578 = 2 (mod 8),
P = -1,
E_odd = 50,
E_even = 528 = 0 (mod 8),
```

as predicted.

## Search consequences

The first nominal improvement `574` is `6 mod 8`, so any sequence with **exactly** `E=574` must have `P=+1`. A hypothetical `E=570` sequence is `2 mod 8` and must have `P=-1`; the product alternates with the two allowed residue classes below the record.

The incumbent and all eight standard LABS symmetry images have `P=-1`. Flipping one sign changes `P`, so Hamming-distance parity from any incumbent symmetry fixes the possible energy residue:

```text
odd Hamming distance  => P=+1 => E=6 (mod 8),
even Hamming distance => P=-1 => E=2 (mod 8).
```

Therefore a target search at an **even** Hamming distance from the incumbent can replace `E<=574` by the strictly stronger exact threshold `E<=570`; at an odd distance `574` remains possible. This is a safe pruning rule for future exact shell/CP-SAT searches.

For CP-SAT formulations that search a whole energy interval rather than one residue, this invariant should be encoded as a redundant parity/modulo relation rather than incorrectly fixing `P=+1`: energies below 574 include both mod-8 classes.
