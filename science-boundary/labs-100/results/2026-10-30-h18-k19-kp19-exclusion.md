# Odd-perfect `(18,0)`, `K=19`, `kp=19,kc=0`: exact exclusion

Date: 2026-10-30

## Scope

This note excludes the `kp=19,kc=0` sub-branch of the odd-perfect `(a,b)=(18,0)`, `K=19` target for `E<=574`.

The full `K=19` arithmetic classification is recorded in

```text
results/2026-10-30-h18-k19-sparse-near-ngp.md
```

and shows that only `W=126,128,130` can occur.  Their order-25 common-PAF data consist of twelve sorted spectral types.  The four types coming from the base multiset `U=1^17 2^7` can carry zero, one, or two antisymmetric defects; the remaining zero-defect `W=130` alternatives require no defect.

For the branch here,

```text
kp = ||p||^2 = 19,
kc = ||c||^2 = 0,
sum p = 9,
sum c = 0.
```

Thus `c=0`, while `p` has exactly six zero coordinates and, among its nineteen nonzero coordinates, fourteen `+1` and five `-1` entries.

## Exact compressed census

The program

```text

```

enumerates all affine orbits of six-zero supports in `Z_25`, then all `C(19,5)` sign choices on each support.  Every candidate is checked against the complete twelve-type `K=19` common-PAF list.

Exact counts are


The `96` compressed hits are only affine representatives.  Because the subsequent aperiodic binary fibre condition is not invariant under every multiplier, they cannot be fibre-tested only in representative form.

## Universal `q=0` fibre table

When `c=0`, also `q=0`, so every binary odd-half lift has

```text
B = [beta,-beta],
beta in {+/-1}^25.
```

For `r=1,...,24`, its negaperiodic autocorrelation difference is exactly

```text
NAF_B(r) = C_B(r)-C_B(50-r) = 2 ACF_beta(r).
```

Global sign of `beta` leaves every ACF unchanged, so fixing `beta_0=+1` is exact.  Exhausting the remaining `2^24=16,777,216` binary fibres and packing their 24 ACF coordinates gives

```text
raw beta fibres  16,777,216
unique ACF keys   8,390,620
```

The exact implementation is

```text
code/oddperfect_h18_k19_q0_fibre.cpp
```

For each compressed `p` representative it restores all `20*25` affine maps and globally deduplicates the resulting signed sequences.  The 96 representatives become exactly

```text
47,500
```

distinct signed affine `p` images.

Each image has six binary `A`-fibre orientation bits, all of which are exhausted.  The base spectral types are queried for defect `0,1,2`; non-base types require defect `0` only.

A subtle implementation hazard was explicitly regression-tested: an unmodified target ACF coordinate can lie outside the binary range while a one- or two-defect change moves it back inside.  The final query therefore does not reject such a target before allowing the sparse defect to repair every out-of-range coordinate.  `--selftest` constructs positive defect-0, defect-1, and defect-2 boundary cases and requires all three to be found.

## Consequence

There is no odd-perfect `(18,0)`, `K=19`, `kp=19,kc=0` binary length-100 candidate with `E<=574`.

This is a strict sub-branch exclusion, not yet an exclusion of all `K=19`.  The next sparse norm split is `kp=17,kc=2`, where `c` has one `+1` and one `-1`; that structure admits a much smaller direct compressed search before any aperiodic fibre stage.
