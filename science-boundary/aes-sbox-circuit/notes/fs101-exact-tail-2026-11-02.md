# FS101 exact-tail superoptimization checkpoint — 2026-11-02

This note freezes the current evidence around the 101-gate Few Shots AES S-box record (`aes101-nist-interface-resub`).  The record is 33 AND + 68 XOR/XNOR = 101 gates and is independently checked on all 256 AES inputs before every experiment below.  Negative results are scoped to the represented family; timeouts are never treated as exclusions.

## Public boundary

As of 2026-11-02, Few Shots still has the 101-gate record.  NIST's current 2026 Circuit Complexity page explicitly lists `G<=100` as an AES S-box target; its official table's smallest listed 2026 gate-count example is G104/A32, so the Few Shots 101 circuit remains the stronger public gate-count seed for this project.

## Linear-only exact window shaving

`fs101_linear_window_refgap.py`, workflow run `41332288868`, used the pinned 2026 `Rohan-Pandey1729/refutation-gap` shortest-SLP CaDiCaL encoding on every represented contiguous linear-only window of length 3..12 inside a maximal run between AND gates.  Each instance preserved the exact live-in/live-out linear map, allowed completely new local XOR/XNOR helpers, and asked for one fewer gate.  Any SAT witness would be spliced into the full circuit and checked on all 256 AES inputs.

Aggregate over 8 shards:

- 90 windows;
- 0 SAT shaves;
- 87 exact UNSAT;
- 3 conflict-budget timeouts, all 12-gate windows inside the initial 14-gate linear run: `(0,12)`, `(1,13)`, `(2,14)`.

This strongly closes small within-one-linear-run redundancies but does not address cross-AND sharing.

## Released-AND `drop two old + one new` direct-100 tails

`fs101_tail_one_new.py`, workflow run `41332341875`, fixed the exact ordered nonlinear atom functions after four cuts (`start=24,27,30,32`).  For every pair of old tail linear functions, it dropped both, took maximal closure of all retained old functions across AND releases, then exhaustively inserted the unique useful new XOR/XNOR helper.  Retained old functions could be regenerated in arbitrary order and move across old AND boundaries whenever their operands were available.  Net local cost is -1, so any completed witness is a 100-gate circuit.

Aggregate:

- all 16 jobs exhausted;
- 316 drop-pairs;
- 4,479 useful helper choices;
- no candidate;
- every nonempty shard's best residual was `[0,1,0]`: all remaining AND atoms released, no retained guide left blocked, exactly one final output absent.

`fs101_tail_residual_diagnostic.py`, run `41332742375`, showed that this repeated residual is not a near-hidden 100-gate circuit.  In the representative `start=24` best state the inserted helper simply regenerates dropped guide 0 and output bit 4 is omitted.  For `start=27,30,32`, the missing output is bit 6; after the helper it is again exactly one XOR/XNOR from the final closure.  The family therefore borrows the gate required for an output rather than creating a net shared saving.

## Exact arbitrary-topology released tail: last AND

`fs101_tail_cadical.py`, workflow run `41332831557`, removed the old-guide restriction entirely.  It fixes the prefix and exact ordered AND atom functions, while every local linear slot is an arbitrary XOR/XNOR of any values available at that temporal stage.

At `start=32` (last AND), the original tail schedule is `[2,1]` = 3 linear gates.

- Baseline `[2,1]`: SAT in 0.006 s, reconstructed 101 gates, all 256 inputs correct.
- Every 2-linear temporal placement is exact UNSAT: `[0,2]`, `[1,1]`, `[2,0]` (3–4 ms each).

Therefore no 100-gate circuit exists in the family with the FS101 prefix fixed before the last AND, the exact last AND function retained, and only two arbitrary local linear gates.

## Exact arbitrary-topology released tail: last two ANDs

`fs101_tail_schedule_census.py`, workflow run `41333031801`, generalized the same calibrated CNF and enumerated every weak composition of one fewer linear gate across the available temporal stages.

At `start=31`, the original tail schedule is `[5,2,1]` = 8 linear gates.

- Baseline `[5,2,1]`: SAT in 0.184 s, reconstructed 101 gates, all 256 inputs correct.
- Target: 7 linear gates across three stages.
- All 36 weak compositions were exact UNSAT.
- 0 SAT, 0 timeout.

Thus the fixed-prefix / exact-last-two-AND family is also completely closed at 100 gates, despite allowing arbitrary new XOR/XNOR topology and arbitrary redistribution of the seven linear slots across both AND boundaries.
