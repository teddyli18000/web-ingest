# G103 linear / tail superoptimization checkpoint — 2026-10-31

This note freezes the evidence from the 2026-10-31 suffix/tail reformulation work.  Negative results are labelled by their represented family; no solver timeout is treated as an exclusion.

## Baseline

Normalized NIST A32/G103 is independently verified on all 256 AES inputs and has 32 AND + 71 XOR/XNOR = 103 gates.  Immediately after the final AND the pure-linear suffix is 22 gates over 17 live boundary values.  A 100-gate circuit with the same nonlinear skeleton needs 68 linear gates total.

## Independent public eRNBP calibration

Workflow `temp-aes-g103-external-erbp.yml`, Run `41193785619`, pinned the public CHES-2025 `lemontrr/Extended-BP-Framework` at commit `11e6b783f179cb9089a08be597d5974e99966e3a` and ran 128 independent RNG seeds on the exact 17->8 G103 suffix map.

All 128 runs returned exactly 25 XOR gates.  Every returned circuit was reattached with exact XOR/XNOR affine polarities and independently checked on all 256 AES inputs, yielding 106-gate full circuits.  This independently validates the suffix-map extraction/reattachment path, but the generic upstream eRNBP heuristic is materially worse than the known 22-gate NIST suffix and should not be scaled.

## Full-suffix shortest-SLP CaDiCaL

`g103_suffix_refgap_sat.py` uses the public 2026 `Rohan-Pandey1729/refutation-gap` shortest-SLP CNF at pinned commit `01349f1b0ee39aef4d9bcf9d75233df6f859eab8`.

Run `41193966869` includes K=19,20,21,22.  The K=22 known-baseline-size instance exhausted 3,000,000 conflicts and returned timeout/unknown after about 184 s (`21,345` variables, `826,471` clauses).  Therefore this generic full-layer encoding is not calibrated for the 17x8 instance; K<22 timeouts are not evidence and should not receive simply larger budgets.  SAT, if any job returns it, remains constructive and must be replayed/all-256 checked.

## Exact contiguous-window shaving

`g103_suffix_window_refgap.py`, Run `41194163960`, exhaustively formed all represented contiguous suffix windows of lengths 3..10 and asked CaDiCaL whether each exact live-in/live-out linear map could be realized with one fewer gate.  Any SAT replacement would be spliced into the complete G103 circuit and checked on all 256 AES inputs.

Aggregate over all 8 shards:

- 132 window instances;
- 0 SAT shaves;
- 128 completed UNSAT instances;
- 4 conflict-budget timeouts;
- the four timeouts were windows `(i,j)=(0,9),(3,13),(9,19),(12,22)`, each old size 9 or 10.

This is strong family-local evidence that the known 22-gate suffix has no easy one-gate redundancy in small contiguous 3..10-gate sub-DAGs.  It does not prove the full suffix optimal.

## Non-contiguous output-cone shaving

`g103_suffix_cone_refgap.py`, Run `41194425465`, changed the decomposition: choose 2..5 final outputs, take their ancestor-closed non-contiguous suffix fan-in cone, preserve every cone live-out used by the untouched suffix, and ask for a one-gate exact shave with completely new local helpers.

Aggregate over all 8 shards:

- 42 distinct cone/interface instances (old cone sizes 6..18);
- 0 SAT shaves;
- 7 completed UNSAT instances;
- 35 conflict-budget timeouts.

The seven exact UNSAT cones have old sizes 6,8,9,10,10,11,11.  Larger cones mostly time out, so this experiment supplies no broad lower bound; its important constructive result is simply that changing from contiguous windows to output-sharing cones still produced no improving candidate.  Candidate quality is flat while excluded local regions grow, so pure-suffix local shaving is deprioritized.

## Architecture reset census: current low-AND public seeds

`low_and_family_census.py`, Run `41194567722`, independently parsed and all-256 verified current NIST low-AND seeds and compared exact nonlinear truth functions / dependency shapes against G103 and the Few Shots 101 record.

- NIST A28/G124: 28 AND + 96 linear, AND depth 5, gate depth 27.
- NIST A29/G137: 29 AND + 108 linear, AND depth 5, gate depth 32.
- A28 vs G103: only 1 shared exact AND function out of a 59-function union; recursive AND-shape hashes differ.
- A28 vs Few Shots 101: 0 shared exact AND functions.
- A29 vs G103: 0 shared exact AND functions.
- A28 vs A29: only 1 shared exact AND function.

Thus A28/A29 are genuinely distinct architecture niches in the current coordinate system, not near-renamings of G103.  A28 is the more plausible reset candidate because reaching 100 requires reducing its linear cost from 96 to 72; A29 would require 108 to 71.  Neither gap is currently small enough to justify assuming it is competitive without a calibrated global-linear synthesis experiment.
